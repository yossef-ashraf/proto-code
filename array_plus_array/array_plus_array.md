**File Name:** `array_plus_array.php`

**Task Description:**

Get the sum of two arrays... actually the sum of all their elements. Each array includes only integer numbers. Output is a number too.

**Example:**

```php
Input:  arr1 = [1, 2, 3], arr2 = [4, 5, 6]
Output: 21 // 1 + 2 + 3 + 4 + 5 + 6 = 21

Input:  arr1 = [-1, -2, -3], arr2 = [-4, -5, -6]
Output: -21

Input:  arr1 = [0, 0, 0], arr2 = [4, 5, 6]
Output: 15
```

**Requirements:**

- Calculate the sum of all numbers in both arrays.
- Use `array_sum()`.
- Achieve **O(n + m)** time complexity and **O(1)** space complexity.
