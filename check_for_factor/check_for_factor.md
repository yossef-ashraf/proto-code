**File Name:** `check_for_factor.php`

**Task Description:**

This function should test if the `factor` is a factor of `base`. Return `true` if it is a factor or `false` if it is not.

**Example:**

```php
Input:  base = 10, factor = 2
Output: true

Input:  base = 9, factor = 2
Output: false
```

**Requirements:**

- Check if `base % factor === 0`.
- Return boolean.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
