**File Name:** `string_repeat.php`

**Task Description:**

Write a function that accepts an integer `n` and a string `s` as parameters, and returns a string of `s` repeated exactly `n` times.

**Example:**

```php
Input:  n = 6, s = "I"
Output: "IIIIII"

Input:  n = 5, s = "Hello"
Output: "HelloHelloHelloHelloHello"
```

**Requirements:**

- Repeat the string `s` exactly `n` times.
- Use PHP's built-in `str_repeat()` function.
- Achieve **O(n * length(s))** time complexity.
