**File Name:** `switch_it_up.php`

**Task Description:**

When provided with a number between 0-9, return it in words.

**Example:**

```php
Input:  1
Output: "One"

Input:  3
Output: "Three"

Input:  0
Output: "Zero"
```

**Requirements:**

- Convert a single-digit integer (0-9) to its English word representation.
- Handle numbers from 0 to 9.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
