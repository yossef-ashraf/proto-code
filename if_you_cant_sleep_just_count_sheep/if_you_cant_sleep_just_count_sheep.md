**File Name:** `if_you_cant_sleep_just_count_sheep.php`

**Task Description:**

If you can't sleep, just count sheep!! Given a non-negative integer `n`, return a string with a murmur: `"1 sheep...2 sheep...3 sheep..."`. If `n = 0`, return an empty string `""`.

**Example:**

```php
Input:  1
Output: "1 sheep..."

Input:  3
Output: "1 sheep...2 sheep...3 sheep..."

Input:  0
Output: ""
```

**Requirements:**

- Build the string murmur counting up to `n`.
- If `n` is 0, return an empty string.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
