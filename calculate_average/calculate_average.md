**File Name:** `calculate_average.php`

**Task Description:**

Write a function which calculates the average of the numbers in a given list. If the list is empty, return 0.

**Example:**

```php
Input:  [1, 2, 3]
Output: 2

Input:  [1, 2, 3, 4]
Output: 2.5

Input:  []
Output: 0
```

**Requirements:**

- Calculate sum of array elements and divide by array count.
- Return 0 if the array is empty.
- Achieve **O(n)** time complexity and **O(1)** space complexity.
