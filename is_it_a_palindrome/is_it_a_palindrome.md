**File Name:** `is_it_a_palindrome.php`

**Task Description:**

Write a function that checks if a given string (case-insensitive) is a palindrome.

**Example:**

```php
Input:  "a"
Output: true

Input:  "aba"
Output: true

Input:  "Abba"
Output: true

Input:  "hello"
Output: false
```

**Requirements:**

- Convert string to lowercase.
- Compare with its reverse (`strrev`).
- Achieve **O(n)** time complexity.
