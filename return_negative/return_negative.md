**File Name:** `return_negative.php`

**Task Description:**

In this simple assignment you are given a number and have to make it negative. But maybe the number is already negative? Zero is not checked for any specific sign.

**Example:**

```php
Input:  1
Output: -1

Input:  -5
Output: -5

Input:  0
Output: 0
```

**Requirements:**

- If the number is positive, make it negative.
- If the number is negative or zero, return it as is.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
