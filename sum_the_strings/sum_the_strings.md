**File Name:** `sum_the_strings.php`

**Task Description:**

Create a function that takes 2 integers in the form of a string as an input, and outputs their sum (also as a string). If either input is an empty string, consider it as zero.

**Example:**

```php
Input:  a = "4", b = "5"
Output: "9"

Input:  a = "34", b = "5"
Output: "39"

Input:  a = "", b = ""
Output: "0"

Input:  a = "2", b = ""
Output: "2"
```

**Requirements:**

- Convert empty strings or numeric strings to integers.
- Sum the two values.
- Return the result as a string.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
