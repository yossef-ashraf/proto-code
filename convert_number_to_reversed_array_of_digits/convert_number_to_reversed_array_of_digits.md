**File Name:** `convert_number_to_reversed_array_of_digits.php`

**Task Description:**

Given a random non-negative number, you have to return the digits of this number within an array in reverse order.

**Example:**

```php
Input:  35231
Output: [1, 3, 2, 5, 3]

Input:  0
Output: [0]
```

**Requirements:**

- Convert number to string, reverse, and extract digits as integers.
- Achieve **O(d)** time complexity where `d` is number of digits.
