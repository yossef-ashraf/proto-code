**File Name:** `sum_without_highest_and_lowest_number.php`

**Task Description:**

Sum all the numbers of a given array, except the highest and the lowest element (by value, not by index!). If array is empty, null, or has 1 element, return 0.

**Example:**

```php
Input:  [6, 2, 1, 8, 10]
Output: 16 // 2 + 6 + 8 = 16

Input:  [1, 1, 11, 2, 3]
Output: 6
```

**Requirements:**

- Remove the minimum and maximum element and sum the remainder.
- Return 0 if array has 0 or 1 element.
- Achieve **O(n)** time complexity and **O(1)** space complexity.
