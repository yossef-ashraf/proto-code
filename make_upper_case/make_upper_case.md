**File Name:** `make_upper_case.php`

**Task Description:**

Write a function which converts the input string to uppercase.

**Example:**

```php
Input:  "hello"
Output: "HELLO"

Input:  "Hello World!"
Output: "HELLO WORLD!"
```

**Requirements:**

- Convert all lowercase letters in the string to uppercase.
- Use PHP's built-in `strtoupper()` function.
- Achieve **O(n)** time complexity where `n` is string length, and **O(n)** space complexity.
