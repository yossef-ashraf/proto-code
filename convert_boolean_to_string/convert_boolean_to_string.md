**File Name:** `convert_boolean_to_string.php`

**Task Description:**

Implement a function which converts the given boolean value into its string representation (`"true"` or `"false"`).

**Example:**

```php
Input:  true
Output: "true"

Input:  false
Output: "false"
```

**Requirements:**

- Return the string literal `"true"` for boolean `true`.
- Return the string literal `"false"` for boolean `false`.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
