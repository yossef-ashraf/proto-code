**File Name:** `reversed_sequence.php`

**Task Description:**

Build a function that returns an array of integers from n to 1 where n > 0.

**Example:**

```php
Input:  5
Output: [5, 4, 3, 2, 1]
```

**Requirements:**

- Return an array of numbers descending from `n` to 1.
- Use `range($n, 1)`.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
