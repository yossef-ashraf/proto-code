**File Name:** `convert_string_to_number.php`

**Task Description:**

We need a function that can transform a string into a number. All inputs will be strings representing valid integers.

**Example:**

```php
Input:  "1234"
Output: 1234

Input:  "605"
Output: 605

Input:  "-7"
Output: -7
```

**Requirements:**

- Convert string representation to an integer.
- Support positive and negative integer strings.
- Achieve **O(n)** time complexity where `n` is string length, and **O(1)** space complexity.
