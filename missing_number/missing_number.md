**File Name:** `missing_number.php`

**Task Description:**

Given an array `nums` containing `n` distinct numbers in the range `[0, n]`, return the only number in the range that is missing from the array.

**Example:**

```php
Input:  [0, 1, 4, 5, 3]
Output: 2 // Numbers are in range [0, 5], missing number is 2
```

**Requirements:**

- All numbers in the array are distinct and in the range `[0, n]`.
- Exactly one number is missing.
- Use the **Gauss Sum Formula** ($S = \frac{n(n + 1)}{2}$).
- Achieve **O(n)** time complexity and **O(1)** extra space complexity.
