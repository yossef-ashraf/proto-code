**File Name:** `sum_of_positive.php`

**Task Description:**

You get an array of numbers, return the sum of all of the positives ones. If there is nothing to sum, the sum is default to 0.

**Example:**

```php
Input:  [1, -4, 7, 12]
Output: 20 // 1 + 7 + 12 = 20

Input:  [-1, -2, -3]
Output: 0
```

**Requirements:**

- Sum only positive numbers in array.
- Return 0 if array is empty or has no positives.
- Achieve **O(n)** time complexity and **O(1)** space complexity.
