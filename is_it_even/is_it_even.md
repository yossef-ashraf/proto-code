**File Name:** `is_it_even.php`

**Task Description:**

In this Kata we are passing a number (float) into a function. Your code will determine if the number passed is even (or not). The function needs to return either a boolean true or false. Numbers may be positive or negative, integers or floats. Floats with non-zero decimals are not even.

**Example:**

```php
Input:  0
Output: true

Input:  0.5
Output: false

Input:  1
Output: false

Input:  2
Output: true

Input:  -4
Output: true
```

**Requirements:**

- Check if number is even and has no decimal part.
- Return boolean `true` or `false`.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
