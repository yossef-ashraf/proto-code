**File Name:** `remove_first_and_last_character.php`

**Task Description:**

Create a function that removes the first and last characters of a string. You are given one parameter, the original string. You don't have to worry with strings with less than two characters.

**Example:**

```php
Input:  "eloquent"
Output: "loquen"

Input:  "country"
Output: "ountr"
```

**Requirements:**

- Remove the first character and the last character of the string.
- Return the remaining substring.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
