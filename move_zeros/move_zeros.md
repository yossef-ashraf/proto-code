
**File Name:** `move_zeros.php`

**Task Description:**

Write a PHP function that moves all zeros in an array to the end while maintaining the relative order of all non-zero elements, without using an additional array.

**Example:**

```php
Input:  [1, 0, 9, 0, 8]
Output: [1, 9, 8, 0, 0]
```

**Requirements:**

- Preserve the relative order of all non-zero elements.
- Move all zeros to the end of the array.
- Use the **Two Pointers** technique.
- Achieve **O(n)** time complexity and **O(1)** extra space complexity.
