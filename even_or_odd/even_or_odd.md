**File Name:** `even_or_odd.php`

**Task Description:**

Create a function that takes an integer as an argument and returns `"Even"` for even numbers or `"Odd"` for odd numbers.

**Example:**

```php
Input:  2
Output: "Even"

Input:  7
Output: "Odd"

Input:  -4
Output: "Even"

Input:  0
Output: "Even"
```

**Requirements:**

- Check if the number is divisible by 2 using the modulo operator `%`.
- Return `"Even"` if the number is even, and `"Odd"` if the number is odd.
- Handle positive, negative, and zero values correctly.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
