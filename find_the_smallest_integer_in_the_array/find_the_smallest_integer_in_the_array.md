**File Name:** `find_the_smallest_integer_in_the_array.php`

**Task Description:**

Given an array of integers your solution should find the smallest integer.

**Example:**

```php
Input:  [34, 15, 88, 2]
Output: 2

Input:  [34, -345, -1, 100]
Output: -345
```

**Requirements:**

- Find the minimum value in array.
- Use `min()`.
- Achieve **O(n)** time complexity and **O(1)** space complexity.
