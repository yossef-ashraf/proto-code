**File Name:** `reversed_words.php`

**Task Description:**

Complete the solution so that it reverses all of the words within the string passed in. Words are separated by exactly one space and there are no leading or trailing spaces.

**Example:**

```php
Input:  "The greatest victory is that which requires no battle"
Output: "battle no requires which that is victory greatest The"
```

**Requirements:**

- Split string into words by space.
- Reverse word order and join with space.
- Achieve **O(n)** time complexity.
