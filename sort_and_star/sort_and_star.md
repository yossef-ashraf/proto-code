**File Name:** `sort_and_star.php`

**Task Description:**

You will be given a list of strings. You must sort it alphabetically (case-sensitive, and based on the ASCII values of the chars) and then return the first value. The returned value must be a string, and have '***' between each of its letters.

**Example:**

```php
Input:  ["bitcoin", "take", "over", "the", "world", "maybe", "who", "knows", "perhaps"]
Output: "b***i***t***c***o***i***n"
```

**Requirements:**

- Sort strings alphabetically (case-sensitive).
- Take the first word and join characters with `***`.
- Achieve **O(n log n)** time complexity.
