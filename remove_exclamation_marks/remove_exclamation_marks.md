**File Name:** `remove_exclamation_marks.php`

**Task Description:**

Write a function `removeExclamationMarks` which removes all exclamation marks from a given string.

**Example:**

```php
Input:  "Hello World!"
Output: "Hello World"

Input:  "Hello! World!"
Output: "Hello World"
```

**Requirements:**

- Remove every `'!'` character from the input string.
- Return the resulting string.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
