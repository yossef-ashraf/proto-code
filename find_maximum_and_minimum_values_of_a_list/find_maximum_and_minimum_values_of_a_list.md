**File Name:** `find_maximum_and_minimum_values_of_a_list.php`

**Task Description:**

Write two functions `findMin` and `findMax` that receive an array of integers as input, and return the lowest and highest number in that array, respectively.

**Example:**

```php
Input:  [-52, 56, 30, 29, -54, 0, -110]
Output (min): -110

Input:  [4, 6, 2, 1, 9, 63, -134, 566]
Output (max): 566
```

**Requirements:**

- Find the minimum value in an array.
- Find the maximum value in an array.
- Achieve **O(n)** time complexity and **O(1)** space complexity.
