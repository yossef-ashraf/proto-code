**File Name:** `beginner_reduce_but_grow.php`

**Task Description:**

Given a non-empty array of integers, return the result of multiplying the values together in order.

**Example:**

```php
Input:  [1, 2, 3, 4]
Output: 24 // 1 * 2 * 3 * 4 = 24
```

**Requirements:**

- Multiply all elements in the array consecutively.
- Return the total product.
- Achieve **O(n)** time complexity and **O(1)** space complexity.
