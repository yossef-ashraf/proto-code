**File Name:** `basic_mathematical_operations.php`

**Task Description:**

Your task is to create a function that performs four basic mathematical operations: `+`, `-`, `*`, `/`. The function takes three arguments: `operation` (string), `val1` (number), `val2` (number), and returns the resulting number.

**Example:**

```php
Input:  operation = '+', val1 = 4, val2 = 7
Output: 11

Input:  operation = '-', val1 = 15, val2 = 18
Output: -3

Input:  operation = '*', val1 = 5, val2 = 5
Output: 25

Input:  operation = '/', val1 = 49, val2 = 7
Output: 7
```

**Requirements:**

- Perform arithmetic operation according to the provided operator string.
- Support addition, subtraction, multiplication, and division.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
