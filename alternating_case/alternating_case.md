**File Name:** `alternating_case.php`

**Task Description:**

Define a function such that each lowercase letter becomes uppercase and each uppercase letter becomes lowercase.

**Example:**

```php
Input:  "hello world"
Output: "HELLO WORLD"

Input:  "HELLO WORLD"
Output: "hello world"

Input:  "hello WORLD"
Output: "HELLO world"

Input:  "1a2b3c4d5e"
Output: "1A2B3C4D5E"
```

**Requirements:**

- Toggle the case of each alphabetic character in the string.
- Non-alphabetic characters remain unchanged.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
