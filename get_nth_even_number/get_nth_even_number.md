**File Name:** `get_nth_even_number.php`

**Task Description:**

Return the Nth Even Number. The input will not be 0.

**Example:**

```php
Input:  1
Output: 0 // The 1st even number is 0

Input:  3
Output: 4 // The 3rd even number is 4 (0, 2, 4)

Input:  100
Output: 198
```

**Requirements:**

- Calculate the nth even number starting from 0.
- Use formula: `($n - 1) * 2`.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
