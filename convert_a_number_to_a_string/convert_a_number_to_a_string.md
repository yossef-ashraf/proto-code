**File Name:** `convert_a_number_to_a_string.php`

**Task Description:**

We need a function that can transform a number (integer) into a string.

**Example:**

```php
Input:  123
Output: "123"

Input:  999
Output: "999"

Input:  -100
Output: "-100"
```

**Requirements:**

- Convert integer to string.
- Use `strval()` or `(string)` cast.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
