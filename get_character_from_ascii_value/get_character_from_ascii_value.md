**File Name:** `get_character_from_ascii_value.php`

**Task Description:**

Write a function which takes a number and returns the corresponding ASCII character for that value.

**Example:**

```php
Input:  55
Output: '7'

Input:  65
Output: 'A'
```

**Requirements:**

- Convert an ASCII integer value to its character representation.
- Use PHP's built-in `chr()` function.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
