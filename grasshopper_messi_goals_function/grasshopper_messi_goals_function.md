**File Name:** `grasshopper_messi_goals_function.php`

**Task Description:**

Messi is a soccer player with goals in three leagues:
- LaLiga
- Copa del Rey
- Champions League

Complete the function to return his total number of goals in all three leagues.

**Example:**

```php
Input:  laLigaGoals = 5, copaDelReyGoals = 10, championsLeagueGoals = 2
Output: 17 // 5 + 10 + 2 = 17

Input:  laLigaGoals = 0, copaDelReyGoals = 0, championsLeagueGoals = 0
Output: 0
```

**Requirements:**

- Sum the goals from the three competitions.
- Return an integer.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
