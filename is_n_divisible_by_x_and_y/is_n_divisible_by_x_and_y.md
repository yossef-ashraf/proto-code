**File Name:** `is_n_divisible_by_x_and_y.php`

**Task Description:**

Create a function that checks if a number `n` is divisible by two numbers `x` AND `y`. All inputs are positive, non-zero numbers.

**Example:**

```php
Input:  n = 12, x = 2, y = 6
Output: true // 12 is divisible by both 2 and 6

Input:  n = 100, x = 5, y = 3
Output: false // 100 is not divisible by 3
```

**Requirements:**

- Check divisibility by both `x` and `y` using the modulo operator `%`.
- Return a boolean (`true` or `false`).
- Achieve **O(1)** time complexity and **O(1)** space complexity.
