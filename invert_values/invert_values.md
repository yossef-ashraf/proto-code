**File Name:** `invert_values.php`

**Task Description:**

Given a set of numbers, return the additive inverse of each. Each positive becomes negative, and the negatives become positives.

**Example:**

```php
Input:  [1, 2, 3, 4, 5]
Output: [-1, -2, -3, -4, -5]

Input:  [1, -2, 3, -4, 5]
Output: [-1, 2, -3, 4, -5]

Input:  []
Output: []
```

**Requirements:**

- Invert the sign of each number in the array.
- Return a new array with the inverted numbers.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
