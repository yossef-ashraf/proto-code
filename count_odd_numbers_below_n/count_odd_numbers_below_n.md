**File Name:** `count_odd_numbers_below_n.php`

**Task Description:**

Given a number `n`, return the number of positive odd numbers below `n`.

**Example:**

```php
Input:  7
Output: 3 // Odd numbers below 7 are [1, 3, 5]

Input:  15
Output: 7 // Odd numbers below 15 are [1, 3, 5, 7, 9, 11, 13]
```

**Requirements:**

- Calculate count of odd numbers strictly less than `n`.
- Use integer division by 2 (`intdiv($n, 2)`).
- Achieve **O(1)** time complexity and **O(1)** space complexity.
