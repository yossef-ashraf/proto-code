**File Name:** `opposite_number.php`

**Task Description:**

Very simple, given a number (integer / decimal), find its opposite (additive inverse).

**Example:**

```php
Input:  1
Output: -1

Input:  14
Output: -14

Input:  -34
Output: 34
```

**Requirements:**

- Return the additive inverse of the number (`-$number`).
- Handle integers and floating-point numbers.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
