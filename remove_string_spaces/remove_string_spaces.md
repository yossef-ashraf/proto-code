**File Name:** `remove_string_spaces.php`

**Task Description:**

Write a function that removes all spaces from a given string, then returns the resultant string.

**Example:**

```php
Input:  "8 j 8   mBliB8g  imjB8B8  jl  B"
Output: "8j8mBliB8gimjB8B8jlB"

Input:  "8 8 Bi fk8h B 8 BBibBl  q "
Output: "88Bifk8hB8BBibBlq"
```

**Requirements:**

- Remove all space characters (`' '`) from the string.
- Use `str_replace()`.
- Achieve **O(n)** time complexity and **O(n)** space complexity.
