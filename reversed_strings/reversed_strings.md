**File Name:** `reversed_strings.php`

**Task Description:**

Complete the solution so that it reverses the string passed into it.

**Example:**

```php
Input:  "world"
Output: "dlrow"

Input:  "word"
Output: "drow"
```

**Requirements:**

- Reverse the given string characters.
- Use the built-in `strrev()` function (or manual iteration).
- Achieve **O(n)** time complexity and **O(n)** space complexity where `n` is the length of the string.
