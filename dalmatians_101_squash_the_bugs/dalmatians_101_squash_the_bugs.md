**File Name:** `dalmatians_101_squash_the_bugs.php`

**Task Description:**

Your friend has been out checking for dogs, but his code is full of bugs! Help him fix the function to return how many dogs he found according to the count:
- <= 10: "Hardly any"
- <= 50: "More than a handful!"
- == 101: "101 DALMATIANS!!!"
- otherwise: "Woah that's a lot of dogs!"

**Example:**

```php
Input:  26
Output: "More than a handful!"

Input:  101
Output: "101 DALMATIANS!!!"

Input:  14
Output: "More than a handful!"
```

**Requirements:**

- Fix conditional checks to return the correct dog message.
- Handle exact condition for 101 dalmatians.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
