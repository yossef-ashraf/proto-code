**File Name:** `rock_paper_scissors.php`

**Task Description:**

Let's play Rock Paper Scissors! You have to return which player won! In case of a draw return `Draw!`.

Rules:
- Scissors beats Paper
- Paper beats Rock
- Rock beats Scissors

**Example:**

```php
Input:  p1 = "scissors", p2 = "paper"
Output: "Player 1 won!"

Input:  p1 = "scissors", p2 = "rock"
Output: "Player 2 won!"

Input:  p1 = "paper", p2 = "paper"
Output: "Draw!"
```

**Requirements:**

- Check for draw first.
- Determine if Player 1 wins, otherwise Player 2 wins.
- Return the exact string required.
- Achieve **O(1)** time complexity and **O(1)** space complexity.
